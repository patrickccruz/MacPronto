Terceira versão de testes do MacPronto, com correções do primeiro boot pelo pendrive. Quem já tem o MacPronto instalado recebe esta versão pela atualização automática.

> [!WARNING]
> **Versão de testes.** A instalação do macOS ainda não foi testada do começo ao fim. Faça backup completo do computador antes de instalar. Leia a [Política de Uso](https://github.com/patrickccruz/MacPronto/blob/main/POLITICA-DE-USO.md).

## Correções

- **O instalador aparece no menu do OpenCore.** No primeiro boot de teste, o menu só mostrava o Windows. O OpCore Simplify liga a opção `HideAuxiliary`, que esconde o macOS Recovery do pendrive. Agora a EFI sai com essa opção desligada, inclusive nas EFIs montadas antes e reaproveitadas.
  - Se você gravou um pendrive com uma versão anterior, não precisa gravar de novo: no menu do OpenCore, aperte a **barra de espaço** para mostrar o "macOS Base System".
- **Pendrive que não responde.** Quando o Windows não consegue apagar o pendrive ("o dispositivo não está pronto"), a mensagem agora explica o que fazer: desconectar e conectar de novo, de preferência numa porta traseira, ou trocar de pendrive. O programa também não perde tempo tentando de novo em GPT nesse caso.
- **Pendrive ejetado.** Um pendrive ejetado e ainda conectado aparece na lista com o aviso para reconectar. Depois do botão "Ejetar com segurança", a tela lembra disso antes de gravar outro.
- **Verificar agora.** Em **Sobre > Atualizações**, o botão consulta o GitHub na hora, mesmo logo depois de uma versão ser publicada.

## Como instalar

- **Já tem o MacPronto instalado:** abra o programa e aceite o aviso da versão nova.
- **Instalação nova:** baixe o `MacPronto-0.1.0-beta.3-instalador.exe` abaixo. Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações** e depois em **Executar assim mesmo**.
- **Portátil:** extraia o `MacPronto-0.1.0-beta.3-portatil.zip` e abra o `MacPronto.exe` de dentro da pasta.
